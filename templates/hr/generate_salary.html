Salary Calculation Formula
  • Per Day Salary = Basic Salary / Total Working Days
  • Leave Deduction = (Absent Days - Allowed Leaves) x Per Day Salary
  • Late Deduction = (Late Days / 3) x (Per Day Salary / 2)
  • Bonus = If 0 absent days → Bonus Per Day x Total Working Days
  • Gross = Basic + Increment + Allowances + Bonus - Leave Ded - Late Ded
  • Tax = Gross x Tax % (from config)
  • Net = Gross - (Leave Ded + Late Ded + Advance + PF + Security + Tax + Other)
